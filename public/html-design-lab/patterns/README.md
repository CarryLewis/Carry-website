# Patterns

Reusable design intelligence. Not snippets copied from a site.

A pattern is abstract enough to move into an unrelated project. Implementation lives in experiments. Adaptation lives in production projects.

## Record

Every pattern uses [`_template.md`](_template.md) and a maturity state:

`DISCOVERED → DECONSTRUCTED → EXPERIMENTAL → VALIDATED → REUSABLE → CORE PATTERN`

## Kinds

- **Original** — first extraction
- **Adaptation** — same principle, new context
- **Variant** — alternative visual or interaction treatment
- **Composite** — combination of patterns (`composites/`)

Never destroy the original when adapting. Create a new file.

## Add a pattern

1. Create `extracted/<slug>.md` or `composites/<slug>.md`.
2. Link references, experiments, and projects.
3. Add a row to [`INDEX.md`](INDEX.md) and [`../lab/knowledge.json`](../lab/knowledge.json).
