# References

Design specimens. Not a screenshot dump. Not a swipe file.

A reference is stored so it can be **deconstructed**. The capture is incomplete until Observation and Interpretation are both written, and kept distinct.

External sites are not copied into this repository. Store metadata, analysis, and extracted pattern names. Link the URL.

## Add a reference

1. Copy [`_template.md`](_template.md) to `external/<slug>.md` (or `internal/` if the specimen is a Lab experiment).
2. Fill metadata.
3. Write Layer 1 (observation) and Layer 2 (interpretation) separately.
4. Deconstruct along visual, spatial, IA, interaction, motion, and storytelling if the specimen warrants it.
5. Name reusable patterns — do not name “the hover effect from Site X.”
6. Link those patterns in [`../patterns/`](../patterns/) (create DISCOVERED records if they do not exist yet).
7. Add a row to [`INDEX.md`](INDEX.md) and an entry to [`../lab/knowledge.json`](../lab/knowledge.json).

Never overwrite an existing analysis. Add a dated addendum or a `v02` file.
