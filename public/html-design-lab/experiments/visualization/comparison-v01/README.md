# Interactive Comparison — v01

## Name

Interactive Comparison

## Problem

Two systems described in adjacent paragraphs cannot be compared on shared structure. Difference hides in prose.

## Concept

Two models occupy the same axes. A slider peels one off the other. A matrix below names the same properties in both.

## Interaction

Slider wipes between Hierarchical and Networked. Toggle a property row to highlight the corresponding part in both diagrams.

## Motion

A clip wipe. Highlight is a stroke change, not a bounce.

## Information Logic

Shared rows = comparable dimensions. The wipe encodes “same frame, different system.” Color marks the active property.

## Reusability

Before/after protocols, competing architectures, visual-language comparison, treatment vs control.

## Technical Approach

CSS clip-path + range input. Data language tokens.
