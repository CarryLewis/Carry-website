# Kinetic Typography — v01

## Name

Kinetic Typography

## Problem

Motion applied to type often decorates instead of encoding hierarchy and sequence. Words bounce; the sentence does not argue.

## Concept

A short statement whose entrance order is the argument: subject, copula, complement, then the qualifier that changes the claim.

## Interaction

Replay. Reduced-motion users see the full sentence immediately.

## Motion

Staggered fade/translate by syntactic role. Emphasis is weight and timing, not bounce or 3D.

## Information Logic

Order of appearance = order of thought. The last line is a revision, which is why it arrives last.

## Reusability

Essay openings, exhibition titles, conceptual framing.

## Technical Approach

CSS transitions + class timeline. Kinetic language tokens.
