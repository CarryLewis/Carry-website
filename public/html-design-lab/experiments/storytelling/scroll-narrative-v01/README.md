# Scroll Narrative — v01

## Name

Scroll Narrative

## Problem

Sequential ideas dumped as a wall of text lose causal order. The reader cannot see when a structure appears, only that it was described.

## Concept

A vertical essay whose stages pin. Beside the text, a diagram is constructed in the same order as the argument: element, relation, system, label.

## Interaction

Scroll. Each section takes over the sticky diagram. No click required.

## Motion

Diagram parts fade and translate into place as their corresponding paragraph becomes current. Motion encodes sequence, not decoration.

## Information Logic

Reading order = construction order. The visual system encodes causality: A exists, then A relates to B, then C emerges from that relation.

## Reusability

Interactive essays, research explanations, system onboarding, conceptual frameworks.

## Technical Approach

HTML + CSS sticky layout + IntersectionObserver. Editorial language tokens.
