# Implementation Mode

Trigger: “Implement this pattern.”

1. Inspect the target architecture.
2. Identify the insertion point.
3. Preserve existing functionality.
4. Implement the smallest appropriate change.
5. Reuse existing tokens where possible.
6. Avoid unnecessary dependencies.
7. Check desktop.
8. Check mobile.
9. Check animation performance.
10. Visually inspect the result.

Do not rewrite unrelated code.
Do not silently restyle the host project into Lab chrome.
Do not overwrite the original pattern record; if the implementation teaches something new, add a variant or a reflection.
