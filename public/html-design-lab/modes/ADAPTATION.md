# Adaptation Mode

Trigger: “Use this design for my project.”

Do **not** start in pixels.

```
Original design principle
    → Target project problem
    → Necessary transformation
    → Adapted pattern
```

Then state, before any implementation:

- What remains (the principle)
- What changes (visual language, density, interaction, content)
- What is refused (poor semantic / visual / cognitive / technical / performance / responsive fit)

Write or update a [`briefs/`](../briefs/) note for the target project.

Only after that: Implementation Mode.
