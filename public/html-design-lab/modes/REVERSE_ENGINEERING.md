# Reverse Engineering Mode

Trigger: “What design system is this using?”

Infer, from the source as it is:

- Typography
- Color
- Spacing
- Layout
- Motion
- Interaction
- Component logic
- Visual hierarchy
- Information architecture

Then write compact **Design DNA** using [`dna/_template.md`](../dna/_template.md).

Example shape:

```
Minimal editorial
+ high whitespace
+ asymmetric composition
+ slow motion
+ contextual navigation
+ semantic accent color
```

Scores in DNA files are discussion tools, not measurements.

Do not “improve” the source while reverse-engineering it.
