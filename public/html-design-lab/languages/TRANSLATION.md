# Design translation

The same principle may be implemented in many visual languages. Preserve the distinction:

**Principle → visual language → implementation**

Do not treat one implementation as the principle.

## Example

Principle: **Reveal complexity progressively.**

| Language | Implementation |
| --- | --- |
| Editorial | Text and diagram parts appear as the argument needs them ([Scroll Narrative](../experiments/storytelling/scroll-narrative-v01/)) |
| Scientific | Diagram elements activate in causal order ([Process Diagram](../experiments/visualization/process-diagram-v01/)) |
| Spatial | Labels resolve as the camera approaches ([Spatial Map](../experiments/layout/spatial-map-v01/)) |
| Data | Events appear along an axis as the playhead advances ([Timeline](../experiments/visualization/progressive-timeline-v01/)) |
| Narrative | Scroll is the clock ([Scroll Narrative](../experiments/storytelling/scroll-narrative-v01/)) |
| Kinetic | Syntactic roles enter in thought-order ([Kinetic Type](../experiments/typography/kinetic-type-v01/)) |
| Simulator | A disturbance then a return ([Mechanism](../experiments/scientific/mechanism-v01/)) |
| Exhibition | A plate, then a numbered region ([Annotation](../experiments/images/layered-annotation-v01/)) |
| Notebook | Clusters encountered by pan, not by chapter ([Canvas](../experiments/layout/infinite-canvas-v01/)) |

When adapting: name the principle first, then choose the language of the **target project**, then implement. Do not drag Lab-shell notebook chrome into a scientific product because the pattern was first drawn here.
