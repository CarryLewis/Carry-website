# Clinical Case Workspace · 公开项目简介

新增静态入口：`/clinical-case-workspace/`。这是个人网站上的项目介绍与合成样例，不是临床工作台应用或资料处理服务。

## 内容与数据

- 项目缘起、四个页面、实际原型截图、可点击工作流和合成来源锚点。
- 原型 fixture 快照：4 个主要页面、3 份合成病例、4 页文档、14 条手工批注、7 项待审核事实。
- 原型验收：2026-11-17 的 13 项自动化测试通过。它们不证明真实 OCR 准确率、模型质量、临床正确性或机构合规。
- 知识库快照：2026-11-17 连接器可见课程库 457 行、疾病库 66 行、病例库 28 行；最后一项包括模板等记录。非空关系分别为课程→疾病 17、疾病→课程 33、疾病→病例 11、病例→疾病 12。它们是有非空关系字段的记录数，不是关系边数、患者数量或原生双向属性验证。

汇总元数据位于 `public/clinical-case-workspace/project-data.json`，页面内的数据展示是同日静态快照，不是实时接口。更新快照时同时修改 JSON、页面标签与日期，再运行检查；不自动采集任何数据。

## 网站入口

- 中文及英文作品列表中的 Clinical Case Workspace 项目条目。
- 项目详情的「打开演示」进入公开 HTML 简介；HTML 已明确说明只是项目展示。
- `/knowledge/medical-basement/` 顶部的项目与架构链接。

HTML 主体沿用用户指定的中文介绍形式；项目条目提供中英文文案。截图只含虚构教学资料。公开页不包含私人 Notion 链接、库 ID、病历正文或私有源码包；不链接独立私有应用仓库。

## 交互与边界

四个介绍 Tab、键盘切换、六阶段工作流详情、合成批注选择与学习语义演示、截图放大。所有交互在当前页面完成，无文件上传、表单提交、模型或 Notion 请求。CSP 限制连接。

## 验证

```sh
node scripts/check-clinical-case-showcase.mjs
npm run build:site
node scripts/check-bilingual.mjs
```

`build:site` 只构建，不运行 Notion 同步。静态产物应包含 `out/clinical-case-workspace/index.html`、数据 JSON、合成截图，以及中英文项目详情路径。

本次只向 GitHub 分支与 PR 提交，不修改现有 Pages/Sites 工作流、域名、Notion 发布策略或托管身份。main 的现有自动发布规则仍然保留；合并 PR 可能触发它。
